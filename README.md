# nlp-segmentation-pos-tagging

An NLP project for **word segmentation and POS tagging** using trigram language models and dynamic programming. The project also explores **morphology-aware tagging** and compares different approaches using standard evaluation methods.

## Features

* Trigram-based word segmentation
* POS tagging using emission and transition probabilities
* Morphology-aware tagging
* Baseline model comparison
* Accuracy and confusion matrix evaluation
* Error analysis

## Technologies

**Python · NLP · Google Colab · Dynamic Programming · Language Modeling**

## Project Type

This is a group academic project with individual contributions to model implementation and evaluation.
